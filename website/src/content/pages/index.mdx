<FeatureGrid
  id="features"
  eyebrow="Capabilities"
  title="Built for live, multi-source video"
  lead="One application to bring every camera, feed and display together, laid out exactly how the show needs it."
>
  <Feature icon="01" title="Multi-protocol ingest">
    NDI, Blackmagic DeckLink, Syphon, Spout, webcams and screen capture, all as first-class sources on the same canvas.
  </Feature>
  <Feature icon="02" title="GPU compositing">
    A wgpu pipeline does YUV to RGB on the GPU with minimal CPU to GPU copies, so the frame rate holds as the grid grows.
  </Feature>
  <Feature icon="03" title="Interactive canvas">
    Drag, resize, snap and zoom sources directly. Zones, borders and labels make each feed identifiable at a glance.
  </Feature>
  <Feature icon="04" title="Per-source control">
    Position, scale, flips, borders and labels are set individually and saved with the project.
  </Feature>
  <Feature icon="05" title="Multi-protocol output">
    Send the composed view out over NDI, DeckLink, Syphon or Spout, or keep it as a clean canvas.
  </Feature>
  <Feature icon="06" title="Native everywhere">
    Real desktop apps for macOS, Windows and Linux, with no browser or plugin in the pipeline.
  </Feature>
</FeatureGrid>
